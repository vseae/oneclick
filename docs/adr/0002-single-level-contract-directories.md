# Single-Level Contract Directories

The Contract Catalog organizes contracts into single-level directories stored in the database, with each contract belonging to at most one directory or remaining ungrouped. This models moving contracts between groups without introducing nested directories or multiple memberships. Deleting a directory returns its contracts to the ungrouped catalog while preserving the contracts and their System Log entries; dragging changes directory membership and retains the existing contract sorting behavior.

Directories follow the catalog's network scope, with unique trimmed names within each network and empty directories allowed. A contract whose network is changed becomes ungrouped in its new network. Directory membership and directory records are included in version 2 backups; version 1 backups restore contracts as ungrouped. Collapse preferences belong to the current browser rather than the shared database, and search temporarily reveals matching contracts without changing those preferences. Desktop users can drag contracts into a directory or back to the ungrouped area; the move dialog provides the same operations on touch devices and can create a directory and move a contract in one operation.

Contract Selection is independent of the Current Contract and resets when the network changes. Selecting all applies to the current search results, including contracts in collapsed directories; the catalog displays the count of selected contracts outside those results. Bulk moves and deletions validate every selected contract against the requested network and execute in one transaction, with a new destination directory created once for the entire selection. Bulk moves preserve System Log entries; bulk deletion follows contract ownership and deletes their logs, with an explicit confirmation listing the selected count.

Contract Selection Mode replaces permanent checkboxes. A contract's context-menu Select action or a Ctrl/Cmd/Shift click enters this mode without changing the Current Contract. Within this mode, an ordinary click selects one contract, Ctrl/Cmd toggles an individual contract, and Shift selects a contiguous range. Escape or the Exit Selection action clears the selection and exits the mode; clicking catalog blank space clears the selection while keeping the mode active. Successful bulk moves or deletions exit the mode, while canceled or failed operations retain it.

Range selection follows the displayed directory and contract order, excluding collapsed directories and contracts hidden by search, but including rows outside the scroll viewport. Ctrl/Cmd+Shift adds a range to the existing selection. Search, sort, and collapse changes preserve the selected set and reset its range anchor. The selection toolbar appears only in Contract Selection Mode; its Select All action and Ctrl/Cmd+A within the catalog preserve the existing search-result scope, including collapsed directories. Text inputs retain native text selection.

Dragging from catalog blank space in Contract Selection Mode draws a selection rectangle; intersecting contract rows are selected, and directories are never selected. A rectangle replaces the selection unless Ctrl/Cmd is held to add contracts. At the viewport edges it scrolls only the contract list. Starting a drag on a contract retains directory movement: dragging a selected contract moves the entire selected set, including selections outside the current search, while dragging an unselected contract moves only that contract. This retains the existing movement gesture rather than making every drag a rectangle. Right-clicking a selected contract retains the set and exposes bulk move/delete; right-clicking an unselected contract within the mode selects only that contract. Touch users retain the long-press or overflow menu and enter the mode through Select.
